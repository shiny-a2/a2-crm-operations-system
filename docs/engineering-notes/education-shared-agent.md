# Education shared assistant candidate

The independent Node Education product has an optional shared text-chat candidate for student guidance and manager work. It uses the same assistant platform as Beauty while retaining the product's own current identity, consent and CRM permissions.

Managers can request scoped reports and propose internal follow-up creation or completion. The preview names the record, assignee and time before an explicit confirmation. Proposing has no business effect; repeat confirmation does not create another task. The interface presents execution status separately from model text.

Fourteen Education regression tests and 15 real cross-product integration checks passed with scripted model output. Eight combined Education/Beauty mobile/desktop light/dark browser cases exercised reports, proposal review, keyboard focus and completion with no page exceptions or horizontal overflow. No real student data, paid model request, external message or production change was used.

Status: source candidate, disabled by default. The published Education demo still uses its earlier simulated guide. Expert-approved academic knowledge, durable chat, an approval inbox, schedules, production authorization and deployment acceptance remain open. See the [shared platform showcase](https://github.com/shiny-a2/a2-intelligence-showcase) for the cross-product scope.
