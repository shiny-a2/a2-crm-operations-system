# Catalog invitation preview

## Update — 2026-10-18

A private CRM release candidate changes how an optional store invitation appears on WooCommerce catalog landings. Product, category and shop visitors can open the existing invitation from a small floating control after they have had access to the page content. Explicit administrator choices and separate marketplace behavior stay within their existing paths.

The candidate also gives the control keyboard focus, returns focus after closing the dialog, limits Escape handling to an open invitation, and respects reduced-motion preferences. These details matter when the same storefront also has a gallery, menu and purchase controls.

Synthetic keyboard checks and a read-only browser preview covered mobile and desktop widths, light and dark themes, and a product and category page. The preview did not submit a contact or make a purchase. An isolated staging check, review of lead-capture expectations and production approval remain before release. Search ranking, Core Web Vitals and conversion effects have not been measured for the candidate.

This note describes user-facing behavior and verification boundaries; the private plugin source and customer data are not published here.
